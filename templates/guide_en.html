1. Choose an observatory, then select a target. Use More targets for additional objects.
  2. The default is the current time in Beijing. Pick a date and time as needed. For multiple results, set Rows and Time step, then click Calculate.
  3. Select a result row to view its finder chart. Use Copy coordinates to copy right ascension and declination.
  4. Use − / + or enter a field of view in arcminutes. Click the chart for fullscreen, or use Save image to download it.
