# 天文卫星星历与寻星图工具 (Ephemeris & Finder Chart Tool)

这是一个基于 Python Flask 的 Web 应用程序，专为天文观测者设计。它可以从莫斯科国立大学 (SAI MSU) 服务器获取高精度的卫星星历数据，并结合 STScI 的 DSS (数字化巡天) 图像生成实时的寻星图，帮助用户在夜空中精确定位木星、土星、天王星和海王星的卫星。

## 🚀 主要功能

### 核心功能
*   **高精度星历计算**: 
    *   对接 SAI MSU `nss-eph3` 接口
    *   支持自定义观测站 (Observatory Code)、具体时间和目标天体
    *   提供多种历表模型选择 (DE441, DE431, INPOP19a 等)
*   **自动化寻星图生成**:
    *   根据计算出的赤经 (R.A.) 和赤纬 (Dec.) 自动从 STScI 下载 DSS 图像
    *   支持自定义视场 (FOV) 大小,默认 10 角分

### 智能功能
*   **北京时间支持**: 输入北京时间(+8),系统自动转换为 UTC
*   **自定义天体**: 支持输入任意 MSU 天体代码 (如 301 表示月球)
*   **自动预览**: 计算完成后自动显示第一条结果的 DSS 图,无需二次点击
*   **实时 UTC 时钟**: 顶部导航栏显示实时 UTC 时间

### 现代化界面
*   **简洁表格展示**: 紧凑的表格布局,大字体易读
*   **一键复制**: 快速复制坐标数据用于望远镜控制软件
*   **交互式预览**: 支持图片全屏查看、缩放、拖拽和平移
*   **响应式设计**: 基于 Tailwind CSS,适配各种屏幕尺寸

## 🛠️ 技术栈

*   **后端**: Python 3, Flask
*   **数据处理**: Requests (HTTP请求), BeautifulSoup4 (HTML解析)
*   **前端**: HTML5, JavaScript (原生), Tailwind CSS (CDN)
*   **数据源**:
    *   星历数据: [SAI MSU Natural Satellites Ephemeride Server](https://www.sai.msu.ru/neb/nss/nss_ephce.htm)
    *   星图数据: [STScI Digitized Sky Survey](https://archive.stsci.edu/cgi-bin/dss_form)

## 📦 安装与运行

### 1. 环境要求

确保已安装 Python 3.8 或更高版本。

### 2. 安装依赖

在项目根目录下运行以下命令安装所需的 Python 库：

```bash
pip install -r requirements.txt
```

*注意: `requirements.txt` 包含 `flask`, `requests`, `beautifulsoup4` 等。*

### 3. 启动应用

运行 `app.py`:

```bash
python app.py
```

终端将显示如下信息：
```
 * Running on http://0.0.0.0:8000/ (Press CTRL+C to quit)
```

### 4. 访问

打开浏览器访问 [http://localhost:8000](http://localhost:8000) 即可使用。

## 📖 使用指南

1.  **设置参数**:
    *   **观测站**: 输入你的观测站代码 (如云南天文台 1米镜为 286,地心坐标为 500)
    *   **目标天体**: 选择预设卫星或输入自定义天体代码 (如 301 表示月球)
    *   **时间**: 支持输入北京时间(+8),留空则使用当前 UTC 时间
    *   **高级参数**: 可调整历表类型、步长、视场 (FOV) 等
2.  **获取数据**:
    *   点击"开始计算",系统将从 MSU 获取数据并自动显示 DSS 预览图
3.  **查看与导出**:
    *   结果表格显示具体时刻的赤经赤纬,大字体易读
    *   点击"复制"按钮快速复制坐标
    *   点击预览图可全屏查看,支持缩放和拖拽
    *   点击"保存图片"下载寻星图

## ✨ 特色功能

*   **智能时间处理**: 自动识别北京时间并转换为 UTC,无需手动计算
*   **一键完成**: 计算后自动预览,省去手动点击预览的步骤
*   **灵活天体选择**: 既可选择预设卫星,也可输入任意天体代码
*   **紧凑布局**: 优化的表格展示,在有限空间内显示更多数据

## 📝 注意事项

*   本工具依赖外部 API (MSU 和 STScI),请确保网络连接正常
*   第一次加载某一天区的 DSS 图像时可能需要几秒钟下载
*   输入时间格式: `YYYY MM DD HH mm ss` (如 2025 02 12 20 00 00)
*   FOV 范围: 1-60 角分,默认 10 角分
